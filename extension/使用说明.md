## 安装

1. Edge 地址栏打开 `edge://extensions`（Chrome 使用 `chrome://extensions`）。
2. 打开“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择本仓库的 `extension` 文件夹，选择有 `manifest.json` 的这一层。已经安装的用户继续使用原安装目录，在扩展管理页点“重新加载”；先保存当前画布并核验 ZIP，再刷新画布加载新版接口。
4. 已经打开的画布会尝试接入保护，无须先刷新。若没有看到“画布保存保护”，点击浏览器扩展列表中的本扩展图标。
5. 旧页面先导出并核验 ZIP。图片组点击补丁要等安装后重新打开的页面才会加载；不要为启用点击补丁而直接刷新尚未保护的旧画布。

## 日常使用

- 1.0.2 按当前画布和最新内容记录保护结果，旧画布的失败不会再显示到当前画布，删除图片后已过期的检查会被跳过。
- 如果删除图片后仍提示缺文件，点“重新检查”。如果其他节点、参考图或聊天记录仍引用它，明细会显示引用位置；不能只隐藏警告后把缺图的包当成完整备份。
- 已安装旧版本时，在扩展管理页点“重新加载”，回到原画布点浏览器工具栏里的本扩展图标。旧页面会新增“重新检查”并自动检查一次，无须先刷新画布。要全面启用按画布隔离状态，先检查并导出完整 ZIP，再重新打开页面。
- 页面出现“已保护”表示当前提交的画布快照和引用媒体已写入独立的本地保护数据库。“正在保护”时先等待；保护失败时会显示具体错误。
- 图片下载/生成写入后再备份文件；画布更新立即记录保护快照，避免原站 400 毫秒延迟写入造成的刷新缺口。原站自动清理不再删除“未使用”的媒体。
- 需要保存文件时直接点“保存完整 ZIP”。使用当前画布状态，收集图片、视频、音频、图片组、参考图，带上布局、连线、提示词、聊天和视图信息。
- 打包前有未完成生成会停止导出；已引用的媒体缺失、临时地址无法读取会显示清单并停止。图片还会检查能否正常解码，防止把错误响应当成图片保存。不会给缺图的包标记成功。
- ZIP 带 `projects.json`、全部引用的媒体和 `guard-manifest.json`。每个文件记录字节数与 SHA-256，生成后重新读取包并校验，再触发下载。
- 下载完成后保留 ZIP。可用“检查 ZIP”检查下载到磁盘的文件，用“恢复 ZIP”校验后恢复成新的画布副本；也兼容原网站“导入画布”。
- “恢复 ZIP”会为媒体重新分配本地键，保留原画布。恢复后在“我的画布”中打开名称带“（恢复）”的画布。
- 仍建议只在一个网站标签页中编辑；扩展会通过保存锁合并不同画布的更新，但没有安装扩展的旧标签页不受控制，同一画布同时编辑也没有协作合并能力。

## 鼠标问题

1.0.1 修复提示消息挡住鼠标的问题：Ant Design 的消息卡片在连续出现或淡出时会覆盖页面中央，鼠标命中这些卡片时变成默认箭头，点击和拖动无法到达下面的画布。扩展让消息文字区域穿透鼠标，继续保留原提示文字和按钮功能。

已安装 1.0.0 的用户，在 `edge://extensions` 找到本扩展，点“重新加载”，然后回到原画布点浏览器工具栏里的本扩展图标。提示消息修复可立即接入旧页面，无须刷新画布。原有本地保护副本继续保留。

网站 v0.4.0 的图片组根节点会把所有子图加入拖动列表，却只允许拖动列表长度为 1 的操作被当作点击，导致点击根图不打开操作面板。补丁单独记录实际按下的节点，保留整组拖动。

画布平移原来只在 `pointerup` 时结束；补上 `pointercancel` 和窗口失焦的结束处理。点“恢复鼠标”可结束残留拖动。

你页面里已有的 `local-canvas-retry-panel` 批量重试工具是最高层浮窗，会拦截其矩形范围内的鼠标。用“收起重试工具”隐藏它，需要时再显示；不会停止或重新提交生成任务。

## 保护边界

- 保护的是已经收到的图片文件。正在生成、尚未从服务端返回的图片，刷新后无法靠扩展继续原请求。
- 必须等状态显示“已保护”。磁盘空间不足、浏览器强制终止、用户绕过离开提示或主动清除网站数据，不能保证未完成的写入。
- 独立本地保护数据库也属于这个网站在本机的数据。清除网站数据/卸载浏览器前，先把校验通过的 ZIP 留到磁盘。
- 已经从数据库和所有可读页面里消失的图片，扩展不能凭空恢复。可读旧图片会尝试从其临时地址抢救。
- 接入已打开的旧页面能读取并备份其内存项目；从下次加载起才全面接管媒体写入和恢复。先备份旧页，再重新打开。
- 点击补丁只替换当前核对过的 `04vm3dhh2jasn.js` 资源。网站升级换了资源名时不会盲目替换；未匹配到保存接口会显示未接入，不宣称已经保护。
- 本扩展通过手动“清理删除缓存”回收确认来自已删除节点且无人引用的媒体。本地占用可通过该按钮管理。没有外发、埋点或云同步，不读取 AI API Key。导出缺失的远程媒体时只尝试原画布已有的媒体地址。
