# 画布助手 · CanvasSaveGuard

为 Infinite Canvas 提供本地保存保护、完整 ZIP 备份、按明确删除记录清理缓存、批量重试和图片组操作的 Edge / Chrome 扩展。

当前版本为 **1.0.43**。

## 安装

1. 下载本仓库的源代码并解压，或使用 `git clone https://github.com/YCQ-cyn/CanvasSaveGuard.git`。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
3. 打开开发人员模式，点击“加载解压缩的扩展”，选择本仓库的 **`extension`** 文件夹，其中应有 `manifest.json`。
4. 打开下表中受支持的画布页面，确认右下角“画布助手”显示接入及保护结果。

更新已有安装时，在扩展管理页重新加载扩展。等当前生成与保存完成、导出并校验完整 ZIP 后，再刷新画布以加载最新接口。

## 适配范围

插件按已核对的网站资源定位补丁。页面显示的版本号相同，也需要入口资源匹配。

| 网站 | 已核对的画布版本 | 入口资源 |
| --- | --- | --- |
| `https://canvas.best` | v0.20.0 | `index-BcbSchFn.js` |
| `https://canvas.modelaryx.com` | v0.4.0 | `04vm3dhh2jasn.js` |

网站更换入口或内部接口后，需要重新适配。请以面板中的实际接入状态为准。

## 功能

- 自动保护画布快照与实际媒体文件，记录提示词、节点位置、图片组、连线及参考素材。
- “保存完整 ZIP”收集引用媒体，写入字节数与 SHA-256，完成校验后下载。“检查 ZIP”和“恢复 ZIP”支持备份核对及恢复。
- 选区附近提供一键展开、一键收起、整理和批量下载。选中收起的图片组时，图片 ZIP 包含其已有主图、组内结果及实际所属的嵌套子图，同组相同媒体编号去重。
- 在 canvas.best 框选多个空白、空闲图片节点，将参考图右侧连线点拖到其中任一目标，可一次给全部所选空节点连线。支持主图与展开子图作为来源，已有连线去重，整批连接可以一次 Ctrl+Z 撤销。
- 全局半网格吸附、保留稀疏行列的中线整理，以及可选的后代节点随动。
- 手动和自动重试沿用逐项提交逻辑，可切换为固定矩形区域，收起组会跳过。区域内新增的失败项也参与后续检查。
- 缓存来源检查按需读取媒体归属，包含屏幕外节点、折叠组和参考素材。

尚无文件的生成中或失败项在图片下载中显示跳过数量。完整画布 ZIP 遇到未完成生成、缺失媒体或校验失败时，会显示原因并停止导出。

## 删除缓存与撤销

清理依据手动删除节点、组内图片、连线或整张画布时记录的对象身份。删除保留 **60 秒**，期间可以使用原站的 Ctrl+Z 撤销，恢复图片、位置和连线。刷新后的撤销能力取决于原站保存的历史。

期满后重新核对当前画布、其他画布、打开的标签页以及参考素材等引用，才回收符合条件的原站媒体、缩略图、保护副本及对应历史。缺少明确删除依据或仍被引用的文件继续保留。下载到电脑的备份 ZIP 独立保存。

## 数据与权限

保存保护使用当前网站的浏览器本地数据库。插件中的清理操作也作用于这些本地数据库。

扩展声明两个受支持画布域名及 `https://image.yydsapi.uno` 的访问权限，并使用 `scripting` 和 `declarativeNetRequestWithHostAccess` 接入已核对的网站资源。远程文件补全使用画布数据中已有的媒体地址，重试通过原站现有的模型渠道提交生成请求。

AI 接口配置继续由画布管理。公开仓库包含程序、构建产物和合成测试，使用者的画布媒体及浏览器数据库由使用者自行管理。

## 开发与验证

在支持当前依赖的 Node.js 环境中执行以下命令。

```sh
npm ci
npm run build
npm test
```

需要运行浏览器测试时，先安装独立的测试浏览器。

```sh
npx playwright install chromium
node tests/archive-browser.mjs
npm run test:browser
node tests/media-session-browser.mjs
```

浏览器测试创建临时配置目录。部分整站测试会访问上表中的原站及其配套资源，站点资源变化会影响测试结果。媒体生命周期测试包含实际的一分钟等待。

1.0.43 已通过 131 项单元测试，以及独立 Chromium 中的 120 个空图片节点批量接线、重复连线去重、整批撤销重做、刷新和 ZIP 恢复验证。图片组展开收起、整理、网格吸附、拖动及批量下载的回归检查通过。长时间使用后的所有浏览器崩溃原因尚未确认。

## 源码与许可证

`src/` 为扩展源码，`scripts/` 为构建和上游补丁脚本，`tests/` 为测试，`extension/` 为可加载产物。`upstream/` 中的固定原始编译资源供补丁构建使用，构建前会核对 SHA-256。

原始 Infinite Canvas 源码以固定提交的子模块提供。需要查阅时执行以下命令。

```sh
git submodule update --init upstream/source-v040 upstream/source-v020
```
